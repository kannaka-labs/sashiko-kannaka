# Component Guide Index

Load guides from the prompt directory based on what the change touches. Each
guide holds the invariants, contracts and known bug patterns for one Kannaka
Labs codebase or area.

A change can match several rows. Load **every** matching guide, not only the
most specific one. Kannaka Labs programs read each other's output, so a change
to a producer (for example `src/bin/kannaka.rs`) should also load the guides of
its known consumers (the Node services and the research harness) when the
change alters what it prints or publishes.

The triggers column lists paths, type names and function names. Matching any
trigger is enough. Paths are relative to the root of the repository named in
the component column.
